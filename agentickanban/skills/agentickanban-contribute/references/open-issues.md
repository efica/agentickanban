# Issue #3: Windows: Codex/Copilot Workspaces öffnen leere CMD-Fenster
Estado: open | Labels:  | Creado: 2026-05-30T21:11:55Z
Beim Starten von Workspaces mit den Providern Codex und Copilot auf Windows erscheint ein sichtbares CMD-Fenster, das inhaltlich leer bleibt.\n\nDieses Verhalten tritt im normalen Workspace-Flow auf und stört die tägliche Nutzung, da bei jedem Start unnötig ein Konsolenfenster kurz/zeitweise sichtbar wird.\n\nErwartung: Workspace-Start von Codex/Copilot ohne sichtbares Terminalfenster.\n\nAuswirkung: Nutzererlebnis ist gestört; visuell auffällig und unruhig, besonders bei häufiger Nutzung.
